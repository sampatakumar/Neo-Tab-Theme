**NeoMorph Theme** is a modern ** Microsoft Edge New Tab Extension** built using **Manifest V3** with a beautiful **Liquid Glassmorphism** design system.

Designed to keep your desktop wallpaper completely unobstructed while providing powerful productivity tools through a sleek, collapsible sidebar.

---

# ✨ Features

## 🎨 Liquid Glassmorphism UI

- Frosted glass interface
- Real backdrop blur
- Dynamic glowing highlights
- Premium animations
- Soft shadows
- Glass cards
- Smooth transitions
- Responsive layout

---

## 📂 Hover Sidebar Drawer

Instead of permanently displaying widgets on the screen, NeoMorph keeps everything hidden inside a beautiful hover drawer.

Features include:

- Animated floating trigger
- Smooth slide animation
- Wallpaper remains fully visible
- Minimal distraction
- Elegant navigation

---

## 🔍 Smart Search

Search directly from your new tab.

Supports:

- Google Search
- Direct website URLs
- Instant navigation
- Keyboard shortcuts

---

## 🕒 Live Clock & Date

Beautiful real-time clock with:

- Live updating time
- Current date
- Clean typography
- Glass styling

---

## 🔖 Bookmark Quick Launch

Launch your favorite websites instantly.

Default shortcuts:

- YouTube
- Gmail
- Google
- GitHub

Additional Features:

- Automatic favicon fetching
- Add new bookmarks
- Delete bookmarks
- Local storage
- Beautiful popup modal

---

## ✅ To-Do List

Stay productive directly from your New Tab.

Features:

- Add tasks
- Complete tasks
- Strike-through completed items
- Delete tasks

## 🖼️ Custom Background Engine

Completely personalize your dashboard.

# 🛠 Installation

## Option 1 — Install from Microsoft Edge Add-ons (Recommended)

Install directly from Microsoft Edge Add-ons:

### Neo Theme

https://microsoftedge.microsoft.com/addons/detail/neo-theme/fppllbcpkjjfpjknbnlbaafklmenplbf

### Extension ID

```
fppllbcpkjjfpjknbnlbaafklmenplbf
```

---

## Option 2 — Install Manually

Clone the repository:

```bash
git clone https://github.com/sampatakumar/Neo-Tab-Theme.git
```

Open:

```
chrome://extensions/
```

or

```
edge://extensions/
```

Enable:

```
Developer Mode
```

Click:

```
Load unpacked
```

Select the project folder.

Open a New Tab.

Enjoy ✨

# 🚀 Why NeoMorph Theme?

Unlike traditional New Tab pages that clutter your screen, NeoMorph Theme focuses on preserving your desktop wallpaper while providing productivity tools only when needed.

### Designed For

- Developers
- Students
- Designers
- Gamers
- Productivity Enthusiasts
- Minimalists

---

# 🔒 Privacy

NeoMorph Theme respects your privacy.

- No tracking
- No analytics
- No external databases
- No account required
- No data collection

All your data—including bookmarks, tasks, themes, and backgrounds—is stored locally using Chrome's storage API.
